# Fix My Code Challenge

## Description
`Fix My Code Challenge` is a project where students jump into an existing codebase, debug issues, and fix them. The goal is to identify logical errors, control flow mistakes, and edge cases in various programming languages like Python, JavaScript, Ruby, and C.

## Repository Structure
- **Directory:** `challenge`
- **Tasks:**
  - `0-fizzbuzz.py`: Python implementation of FizzBuzz
  - `1-print_square.js`: JavaScript script to print a square of `#`
  - `2-sort.rb`: Ruby script to sort arguments in ascending order
  - `3-user.py`: Python class for User model and password hashing validation
  - `4-delete_dnodeint/`: C project for deleting a node at a specific index in a doubly linked list
